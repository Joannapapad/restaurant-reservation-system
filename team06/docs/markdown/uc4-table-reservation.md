# ΠΧ4. Κράτηση Τραπεζιού

**Πρωτεύων Actor**: Πελάτης

**Ενδιαφερόμενοι**  

**Πελάτης**: Θέλει να κάνει κράτηση στο κατάστημα.

**Καταστηματάρχης**: Θέλει να αποδεχτεί ή να απορρίψει αίτημα για κράτηση τραπεζιού ενός πελάτη.

**Προϋποθέσεις**: Να έχει εγγραφεί ο πελάτης στην εφαρμογή.

## Βασική Ροή

### Α) Αναζήτηση Καταστήματος [(UC8)](/docs/markdown/uc8-search-stores.md)

1. Ο πελάτης  με βάση φίλτρων ή προτιμήσεων αναζητά το κατάλληλο κατάστημα για να κάνει την κράτηση (αναλυτικά στο uc8).
2. Ο πελάτης επιλέγει το κατάλληλο κατάστημα
3. Εισάγει τις κατάλληλες πληροφορίες της κράτησης(αριθμό ατόμων, σημείωση, ημερομηνία).
4. Ολοκληρώνεται η αίτηση για κράτηση.
5. Ο πελάτης αναμένει ενημέρωση επιβεβαίωσης.

## Εναλλακτική Ροή

*5α. Ο πελάτης θέλει να κάνει αίτημα για κράτηση σε παραπάνω από ένα κατάστημα:*

1. Η περίπτωση χρήσης επιστρέφει στο βήμα 1.

*5β. Ο πελάτης θέλει να ακυρώσει την κράτηση του:* 

1. Ο πελάτης προβάλει τα αιτήματα που έχει κάνει.
2. Επιλέγει το αίτημα που θέλει να ακυρώσει.
3. Ακυρώνει το αίτημα.
